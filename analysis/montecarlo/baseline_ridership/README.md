# baseline_ridership/ — Stage 3 output

Generated by `analysis/montecarlo/baseline_ridership.py --build`. All files
tracked. Sources are the tracked intermediates in `stars_seattle/`, `rc_seattle/`,
and `school_directory/` — no untracked data needed.

## Files

### `school_routes.csv` — 1,666 rows

Per school_id × program × year (9 school years, 2017-18..2025-26, 6 programs,
98 SPS schools). Non-SPS destinations (out-of-district, service sites) excluded.

| Column | Description |
|---|---|
| `school_id` | 3-digit SPS site number |
| `school_year` | STARS string label ("2024-2025") |
| `year` | int fall start (2024 for 2024-25) |
| `program` | basic / gifted / special_ed / early_ed / bilingual / homeless |
| `n_routes` | distinct routes serving this school×program×year |
| `avg_distance_mi` | mean of per-route average_distance (miles) |
| `avg_stops` | mean stop count per route (= total_stops / n_route_rows) |

Source: `stars_seattle/routes_by_school_year.csv` joined via `school_directory/stars_name_map.csv`.

### `school_enrollment.csv` — 1,056 rows

Per school_id × year (11 years, 2014-15..2024-25, 98 SPS schools).

| Column | Description |
|---|---|
| `school_id` | 3-digit SPS site number |
| `year` | int fall start |
| `enrollment` | total students ("All Grades" from RC) |
| `low_income`, `homeless`, `highly_capable`, `students_with_disabilities`, `english_language_learners` | demographic counts |

Source: `rc_seattle/enrollment.csv` "All Grades" rows, joined to school_directory via `school_code`.
9 non-SPS schools (Interagency, Middle College, etc.) excluded.

### `district_targets.csv` — 9 rows, one per school year

District-level calibration targets averaged across quarters per year.

Key columns for calibration:
- `basic_students_on_buses` — yellow-bus riders (THE primary calibration target)
- `basic_students_in_walk_areas` — pins the eligibility stage
- `special_students_gifted` — gifted-program riders
- `routes_basic`, `routes_gifted`, `buses_basic` — route/bus counts
- `is_covid` — True for 2020-21 (near-zero ridership; exclude from calibration fits)

**2024-25 baseline values:** 10,008 basic on-bus, 1,316 gifted, 202 basic routes.

Note: 2018-19 missing FALL quarter (only SPRING + WINTER in source). 2024-25 and
2025-26 missing SPRING (year not yet complete). Values are means of available quarters.

### `kernel_check.csv` — 60 rows

Per school_id × year: basic vs gifted distance comparison, for the 17 schools
that have BOTH basic and gifted routes in the same year.

**Key result:** Kernel hypothesis strongly confirmed:
- District-level: gifted routes avg 2.56 mi (2017-18) → 3.06 mi (2025-26);
  basic avg 1.71 → 1.54 mi (gifted ≈ 2× basic distance).
- 88.3% of school×year rows (non-COVID) have gifted > basic distance.
- 7 exceptions are all close to parity (ratio 0.86-0.98), in years with few
  gifted routes (low-count noise: Lafayette 2018 with 1 route, Fairmount Park 2017).
- **2024-25 among schools with both programs:** 4/4 have gifted > basic
  (Hamilton 1.26×, Jane Addams 1.57×, Robert Eagle Staff 1.01×, Washington 1.31×).

Pure HC pathway schools (Cascadia, Decatur, Thurgood Marshall) have NO basic
routes in 2024-25 — they serve only gifted program students, so they don't
appear in kernel_check. This confirms the kernel design: their draw is entirely
HCC, not neighborhood assignment.

## Usage in downstream stages

```python
from analysis.montecarlo.baseline_ridership import (
    load_school_routes, load_school_enrollment,
    load_district_targets, load_kernel_check,
)

# Calibration targets for stage 7 (eligibility)
targets = load_district_targets()
baseline_walk_riders = targets.loc[targets['year']==2024, 'basic_students_in_walk_areas'].iloc[0]

# Enrollment marginals for stage 6 (IPF)
enr = load_school_enrollment()
enr_2024 = enr[enr['year'] == 2024].set_index('school_id')['enrollment']

# Route counts for stage 8 ridership soft target
routes = load_school_routes()
basic_routes_2024 = routes[(routes['year']==2024) & (routes['program']=='basic')]
```
