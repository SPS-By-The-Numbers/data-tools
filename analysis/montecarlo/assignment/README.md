# assignment/ — Stage 6 output

Generated by `analysis/montecarlo/assignment.py --build`. All files tracked.
Sources are tracked intermediates only (`census_seattle/`, `section4/`,
`school_directory/`, `rc_seattle/`) plus the shapefiles for the attendance
overlays — no network needed.

## `assignment_matrix.csv` — ~19k cells

The baseline (2024-25) assignment distribution: where the children of each
block group go to school, per grade band.

| Column | Description |
|---|---|
| `GEOID` | 12-digit census block-group GEOID |
| `school_id` | 3-digit SPS site number |
| `grade_band` | `es` (K-5) / `ms` (6-8) / `hs` (9-12) |
| `n_expected` | expected children from this BG attending this school |
| `p` | P(school \| BG, band) — sums to 1 per (GEOID, grade_band)* |

\* Except ~11 BG-bands with < 0.03 expected children, where cells below the
1e-4 output floor were dropped.

### Construction (OD-anchored IPF)

1. **BG → area weights**: area-weighted overlay of block groups with the
   ES/MS/HS attendance-area layers (ES areas tile SPS territory; min BG
   coverage 0.963).
2. **Observed flows**: Section 4 od.csv → P(school | attendance area, band).
   ES rows = unbanded + K-5 blocks (K-8 attendance schools); ES "6-8" rows
   are excluded (those students are counted in the MS OD keyed by MS areas).
   Non-school destinations (Interagency, Private SpEd, …) dropped and
   renormalized. 100% of names resolve via `school_directory`.
3. **Marginals**: rows = synth_pop children per BG (scaled per band to the
   enrollment total: ×0.93 es, ×0.87 ms, ×0.95 hs); columns = RC per-grade
   enrollment 2024-25 aggregated to bands, 98 SPS schools (PK excluded).
4. **IPF** per band; columns exact, max row residual ≈ 0.

Band totals: es 22,993 / ms 10,621 / hs 15,122 (= RC band totals for the 98
SPS schools; the gap to 49,765 is PK + the 197-student non-SPS-program tail).

## `kernel_params.csv` — option draw-kernel decay fits

Exponential distance-decay length per band, grid-fit so that
kids(BG) × exp(−d/L) reproduces each option school's observed draw
distribution over residence areas (mean total-variation distance across
schools; "uniform" = no-decay per-kid baseline it must beat).

| band | n_schools | decay (mi) | mean TV | TV uniform |
|---|---|---|---|---|
| es | 13 | 0.50 | 0.283 | 0.749 |
| ms | 7 | 0.50 | 0.183 | 0.718 |
| hs | 2 | 1.50 | 0.361 | 0.460 |

Used only for SCENARIO generalization (option conversion/move); the baseline
matrix above is anchored to the observed OD, not the kernels.

## Usage

```python
from analysis.montecarlo.assignment import (
    load_assignment, load_kernel_params,
    build_matrix, kernel_bg_weights,
)

m = load_assignment()                      # baseline matrix
# One MC draw (paired design, Stage 10):
from analysis.montecarlo.synth_population import sample_synth_pop
import numpy as np
m_draw = build_matrix(pop=sample_synth_pop(np.random.default_rng(0)))
# Scenario kernel column for a converted/moved school:
w = kernel_bg_weights(977, "option", "es")   # Thornton Creek, fitted decay
```
