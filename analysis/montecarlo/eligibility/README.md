## `walker_fractions.csv` — ~2.8k rows

| Column | Description |
|---|---|
| `GEOID` | 12-digit census block-group GEOID |
| `school_id` | 3-digit SPS site number (101 schools incl. 4 closed/leased sites) |
| `walk_frac` | fraction of the BG's SPS-territory area inside this school's walk zone |

Only nonzero pairs are stored; a missing (GEOID, school_id) pair means
walk_frac = 0 (fully bus-eligible). The denominator is `sps_area_sqft`,
matching how synth_pop weights children by `sps_frac`.

Interpretation: a child assigned to school S from block group G is a *walker*
(not bus-eligible) with probability walk_frac(G, S).

**Do not** calibrate walker counts against STARS
`basic_students_in_walk_areas` (~96-324/yr) — that column is a reporting
adjustment, not a count of children living in walk zones (NOTES.md s5
correction).

## Scenario use

`walk_fractions(walkzones=<GeoDataFrame>)` recomputes the table for any
scenario polygons (resized walk zones) with `school_id` + `geometry` in
EPSG:2926.
