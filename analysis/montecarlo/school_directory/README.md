# school_directory/ — Stage 2 output

Generated by `analysis/montecarlo/school_directory.py --build`. All files are
tracked (no untracked source data required after build — source is the
`parse_shapes` shapefiles + `stars_seattle/` intermediates + `out_enrollment/`).

## Files

### `schools.csv` — 98 rows, one per SPS location school

| Column | Type | Description |
|---|---|---|
| `school_id` | int | 3-digit SPS site number (universal join key) |
| `school_code` | int | 4-digit OSPI building code (links to SAFS pipeline) |
| `name` | str | Canonical short name (from Jan 2025 locations shapefile) |
| `level` | str | ES / MS / HS |
| `classification` | str | `neighborhood` / `option` / `hcc_pathway` / `service` |
| `is_hcc_site_current` | bool | HC pathway site in 2023-25 config (TM, Cascadia, Decatur) |
| `is_hcc_site_proposed` | bool | + Alki, Rainier View in proposed 2025 map |
| `is_hcc_site_historical` | bool | + Fairmount Park (2017-22), before TM replaced it in W. Seattle |
| `has_gifted` | bool | Has any STARS gifted-program routes (any year 2017-26) |
| `has_bilingual` | bool | Has any STARS bilingual-program routes |
| `has_early_ed` | bool | Has any STARS early-ed routes |

**Classification** is derived from the `status` field in the locations shapefile:
- `HC` → `hcc_pathway` (currently Cascadia and Decatur — dedicated HC pathway buildings)
- `Option ELEM` / `Option HS` → `option`
- `Service School` → `service` (just Nova HS in Jan 2025 data)
- `ELEM` / `MS` / `HS` → `neighborhood`

Note: `is_hcc_site_*` flags capture HC pathway sites that are NOT classified as
`hcc_pathway` — e.g., Thurgood Marshall is `neighborhood` (has its own attendance
area) but is also the primary HC ES site for much of the district. The simulation
uses both `classification` and `is_hcc_site_current` to assign draw kernels.

### `stars_name_map.csv` — 154 rows

Maps every STARS `destination_name` (from `stars_seattle/destinations.csv`) to a
`school_id`. Also written back into `stars_seattle/destinations.csv` to fill that
file's previously-blank `school_id` column.

| Column | Description |
|---|---|
| `name` | Raw STARS destination_name |
| `school_id` | school_id (Int64, NA for non-SPS/service/out-of-district) |
| `match_type` | `exact` / `fuzzy` / `manual` / `non_school` |

**Match type breakdown:** 77 exact normalized, 37 manual override, 36 non-school
(service/out-of-district/contract, school_id=NA), 4 fuzzy.

The 4 fuzzy matches are all clear correct matches:
- `B.F. Day Elementary` → 218 (punctuation variant of "B F Day")
- `Genesse Hill Elementary` → 270 (source typo for "Genesee Hill")
- `Sandpoint Elementary` → 269 ("Sand Point" alternate spelling)
- `Viewland Elementary` → 276 (old spelling; "Viewlands" from 2018-19 on)

### `section4_name_map.csv` — 197 rows

Maps every unique school/residence_area name from `out_enrollment/section4_od.csv`,
`section4_attendees.csv`, and `section4_option_draw.csv` to a `school_id`.

| Column | Description |
|---|---|
| `name` | Raw Section 4 name (as-is from enrollment_reports.py output) |
| `school_id` | school_id (Int64, NA for non-SPS entries) |
| `match_type` | `exact` / `manual` / `non_school` |

**Match type breakdown:** 113 exact, 40 manual, 44 non-school (programs,
agencies, closed/out-of-district schools → NA).

Non-school entries (school_id=NA) include: home school records, private/parochial
SpEd placements, Cascade Parent Partnership Program (and its many abbreviations),
InterAgency, Middle College, closed schools (Schmitz Park, Northgate, Van Asselt,
South Lake), out-of-SPS sites (Alan T. Sugiyama, World School), and aggregate
rows (TOTAL, Non-Res, Out of District/Unknown, Education Service Centers).

## How to use in downstream stages

```python
from analysis.montecarlo.school_directory import (
    load_schools, load_stars_name_map, load_section4_name_map
)

schools = load_schools()          # 98 rows, school_id is the join key
stars_map = load_stars_name_map() # Series: destination_name → school_id
s4_map = load_section4_name_map() # Series: section4_name → school_id

# Join STARS routes to school_id:
routes["school_id"] = routes["destination_name"].map(stars_map)

# Join Section 4 OD to school_id:
od["school_id"] = od["school"].map(s4_map)
od["area_school_id"] = od["residence_area"].map(s4_map)
```
