data-tools content scripts

Browser console scripts for scraping public data portals. Open the target page, open DevTools (⌥⌘I), and either paste the full script (Copy script) or paste the loader one-liner, which fetch()es and runs the script without copying the whole body.

OSPI STARS reports

Walks every (year × report type × organization) combination on the OSPI Student Transportation Allocation Reporting System page and downloads every listed document, prefixing each filename with the three selection labels.

Target page: ospi.k12.wa.us/…/student-transportation-allocation-stars-reports
