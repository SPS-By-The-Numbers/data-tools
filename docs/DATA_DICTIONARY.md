### `sps-btn-data.ospi_fiscal.d_fiscal_source`

Dimension table for the _source path column on every fiscal fact table. Each row corresponds to a single scraped PDF (or other document) under data/fiscal/. The _source path repeats up to ~60x per row across fact tables; replacing it with the integer source_id FK cuts substantial size from the CSV outputs.

- **Provenance:** Parsed from OSPI PDFs under `data/fiscal/fiscal` (source_dim).
- **Canonical source:** this table (facts appear nowhere else).
